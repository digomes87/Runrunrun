# Runrunrun 🦀

A loose Rust playground — no roadmap, no tickets, no pressure. Just me vs. the borrow checker, one panic at a time.

## What is this?

This repo exists for one reason: **getting the hang of Rust**. It's where I dump experiments, break things on purpose, and slowly start to understand *why* the compiler is yelling at me (and maybe even agree with it sometimes).

If you're expecting a polished crate with CI badges and a changelog... this is not that. This is a lab bench.

## The rules of the game

- Nothing here is "production ready". It's not supposed to be.
- Code will be refactored, rewritten, and deleted without ceremony.
- Every error message fought is a lesson earned.
- `unwrap()` is fine here. This is a judgment-free zone. (Mostly.)

## Running it

```bash
cargo run
```

That's it. If it compiles on the first try, I got suspicious.

## Why "Runrunrun"?

Because the Rust compiler keeps me running. And because `run cargo run` sounded funny at 11pm.
